# 毅川救我 · 公主抢救计划

v0.4.7 将游戏重做为俯视角自动战斗肉鸽。策划杨梓亮抢走了毅川的 ChatGPT 公主，穿过办公室、迭代工坊和策划城堡，将她救回来。

## 运行

下载：[v0.4.7 Windows 版](https://github.com/Biscuits-Lab/yichuan-save-me/releases/tag/v0.4.7)。

双击 `开始游戏.cmd`，或运行 `build/windows-v0.4.7/毅川救我.exe`。Windows 版资源内嵌，可独立运行，无需安装 Godot。便携包：`build/毅川救我-v0.4.7-公主抢救计划-Windows-x64.zip`。

源码使用 Godot 4.5.2，打开 `project.godot` 后按 F5。缺少运行时可运行 `python tools/bootstrap.py`。

## 玩法

- 战场铺满窗口，没有常驻地图和文字侧栏。WASD / 方向键移动，武器自动瞄准攻击，空格 / Shift 无敌冲刺。
- 三层地牢分别生成 10、11、12 个四向连接的房间。普通怪物房缩小为 800×544 到 1152×736，精英房为 1152×768，关底房为 1344×896，NPC 会客室保持 512–576×352–416；保留随机大小和布局，房间间距同步收紧。房间之间有真实的 176 像素宽走廊，同一层内可连续步行，不重置角色位置；镜头平滑跟随角色，HUD 固定在屏幕上。第一层为办公室，后两层为工坊和城堡。
- 战斗房两波：第一层每波 12／16 只，第二层 15／19 只，第三层 18／22 只。精英房前两波各增加 4 只，最后一波由精英首领大鲨鱼守关；刷怪避开玩家与障碍，并尽量保持怪物间距。走进战斗房内部才触发刷怪与封路，清空后自动拾取积分、开启出口并打开补给商店。关闭商店继续探索，回到房间中央按 E 可以再次购物。重返已清空房间不会重新刷怪。
- 击败每层关底首领后免费三选一提升技能，选择后进入下一层；最终首领选择后救回公主。战意、疾风、强健、再生、瞬身、洋葱守护分别强化伤害、攻速、生命、恢复、冲刺和 Q 守护，本局可叠加升级。
- 积分用于购买武器、装备、刷新货架和付费训练。累计积分与可花余额分别记录，出售不会刷高分。每局初始有 30 积分。
- 商店每轮提供两张武器卡和两张装备卡，买完可手动刷新出新货架。同一商店首次刷新免费，之后依次收取 4、6、8…积分；关闭再打开会保留货架与刷新次数。
- 六种武器：断点太刀、提交手枪、提示词法杖、热修复长枪、需求霰弹枪、回滚力场。支持多武器同时自动攻击，每把独立冷却。
- 六种装备影响护甲、移动、攻速、伤害、恢复和生命上限。武器与装备各最多携带 6 件。
- Esc / Tab 打开背包并暂停。两件同名、同品质物品可合并一级：普通 → 精良 → 史诗 → 传说。武器或装备栏满时，获得同名同品质物品会自动合并，并与已有的更高品质副本连续合并；商店购买、宝库和 NPC 赠礼均适用。未满栏时保留手动合并；无法合并时不扣积分、不消耗商品或礼物。可出售物品，但至少保留一把武器。
- 每层 NPC 房与商店房合计随机生成 0–1 间，腾出的房间全部用于战斗；随机商店房、硬币游商和每间怪物房清空后的补给可出售物资。入口没有商店终端。专门的商店房全场 85 折。宝库可领取一把精良武器，驿站恢复 40 生命，均每房一次。
- 房间与走廊入口不再绘制大门，战斗封路时仅显示小型贴图预警。地板和墙体按房间缓存并交给引擎剔除，角色、敌人和弹丸采用渲染插值，减少镜头移动时的跳帧感。
- 休闲 / 标准 / 硬核在开局前选择。倒下结束本局；重新开局重置积分、装备、技能和同伴，最高纪录保留。旧横版纪录不受影响。

## NPC

每层 NPC 会客室与商店房合计最多一间，也可能没有；出现 NPC 会客室时，从八位 NPC 中随机选择一位角色。战斗房、精英房和首领房不安排交互 NPC，清房后也不会出现；会客室禁止刷怪。接近 NPC 后按 E 交谈。海德骑士作为已招募战友可以同行战斗。

| NPC | 台词 | 服务 |
| --- | --- | --- |
| 若宇 | this is the way | 免费恢复 35 生命 |
| 罗德 | 给毅川派活 | 下一间战斗房追加一波，完成获得 45 积分，会客室保持安全 |
| 海德骑士 | 毅川救我 | 跟随当前层，自动近战；换房保留，换层离队 |
| 八桑 | 好他妈卡我草了 | 花 12 积分，本局武器伤害 +12% |
| 菈雅 | 这条路我熟，带上这个吧。 | 免费赠送随机武器或装备；满栏可自动合并，没有可接收物品时保留礼物 |
| 硬币 | 别赌运气，积分花在刀刃上。 | 出售可刷新的武器和装备 |
| 洋葱骑士哈少 | 学习学习 | 解锁 Q 洋葱守护：范围震退和伤害、2 秒护盾、10 秒冷却 |
| 嘉豪 | 装备到位，直接开干。 | 免费把一把携带武器提升一个品质，最高传说，每次偶遇一次 |

毅川保留“来了”“救命”“哦豁，完蛋”“坏啦”“怀不上了”等口头禅。开场、层间和结局串起公主救援剧情，第三层最终首领为杨梓亮。前两层首领具有弹幕、蓄力预警和狂暴阶段。

## 美术

角色、NPC、公主、首领、怪物、武器装备、墙体和地图道具均使用内置 **imagegen** 生成，并实际接入游戏。刀光、命中火花、魔法爆发、冲刺拖尾使用逐帧像素图集，弹丸、枪口火焰、护盾和蓄力预警也使用生成贴图；这些世界美术不使用矢量线条、圆环或多边形绘制。武器带后坐与轻微命中镜头震动。办公桌采用固定尺寸并保持原图比例，大型摆放使用多张桌子组合。入口不再绘制大门。素材在 `assets/generated/dungeon/`；图集映射、生成提示词和限制见 `docs/dungeon-art.md`。中文和按钮由引擎绘制。
