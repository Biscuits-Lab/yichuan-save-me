# 毅川救我 · 公主抢救计划

v0.4.2 将游戏重做为俯视角自动战斗肉鸽。策划杨梓亮抢走了毅川的 ChatGPT 公主，穿过办公室、迭代工坊和策划城堡，将她救回来。

## 运行

下载：[v0.4.2 Windows 版](https://github.com/Biscuits-Lab/yichuan-save-me/releases/tag/v0.4.2)。

双击 `开始游戏.cmd`，或运行 `build/windows-v0.4.2/毅川救我.exe`。Windows 版资源内嵌，可独立运行，无需安装 Godot。便携包：`build/毅川救我-v0.4.2-公主抢救计划-Windows-x64.zip`。

源码使用 Godot 4.5.2，打开 `project.godot` 后按 F5。缺少运行时可运行 `python tools/bootstrap.py`。

## 玩法

- 战场铺满窗口，没有常驻地图和文字侧栏。WASD / 方向键移动，武器自动瞄准攻击，空格 / Shift 无敌冲刺。
- 三层地牢分别生成 10、11、12 个四向连接的房间。房间尺寸从 736×544 到 1792×1216，大小、长宽与障碍布局随种子变化。房间之间有真实的 176 像素宽走廊，同一层内可连续步行，不重置角色位置；镜头平滑跟随角色，HUD 固定在屏幕上。第一层为办公室，后两层为工坊和城堡。
- 战斗房两波，精英房三波。走进战斗房内部才触发刷怪与封门，清空后自动拾取积分、开启出口，再沿走廊进入其他房间。重返已清空房间不会重新刷怪。每层首领战胜利后，到中央传送门按 E 换层。
- 积分用于购买武器、装备、刷新货架和付费训练。累计积分与可花余额分别记录，出售不会刷高分。每局初始有 30 积分。
- 六种武器：断点太刀、提交手枪、提示词法杖、热修复长枪、需求霰弹枪、回滚力场。支持多武器同时自动攻击，每把独立冷却。
- 六种装备影响护甲、移动、攻速、伤害、恢复和生命上限。武器与装备各最多携带 6 件。
- Esc / Tab 打开背包并暂停。两件同名、同品质物品可合并一级：普通 → 精良 → 史诗 → 传说。可出售物品，但至少保留一把武器。
- 每层 NPC 房与商店房合计随机生成 0–1 间，腾出的房间全部用于战斗；只有商店房或硬币游商出售物资，普通房间和入口没有商店终端。专门的商店房全场 85 折。宝库可领取一把精良武器，驿站恢复 40 生命，均每房一次。
- 休闲 / 标准 / 硬核在开局前选择。倒下结束本局；重新开局重置积分、装备、技能和同伴，最高纪录保留。旧横版纪录不受影响。

## NPC

每层 NPC 会客室与商店房合计最多一间，也可能没有；出现 NPC 会客室时，从七位 NPC 中随机选择一位角色。战斗房、精英房和首领房不安排交互 NPC，清房后也不会出现；会客室禁止刷怪。接近 NPC 后按 E 交谈。海德骑士作为已招募战友可以同行战斗。

| NPC | 台词 | 服务 |
| --- | --- | --- |
| 若宇 | 我这显示是对的 | 免费恢复 35 生命 |
| 罗德 | 给毅川派活 | 下一间战斗房追加一波，完成获得 45 积分，会客室保持安全 |
| 海德骑士 | 毅川救我 | 跟随当前层，自动近战；换房保留，换层离队 |
| 只狼 | 好他妈卡我草了 | 花 12 积分，本局武器伤害 +12% |
| 菈雅 | 这条路我熟，带上这个吧。 | 免费赠送随机武器或装备；满栏不消耗礼物 |
| 硬币 | 别赌运气，积分花在刀刃上。 | 出售可刷新的武器和装备 |
| 洋葱骑士哈少 | 嗯——先想一想，再一起上！ | 解锁 Q 洋葱守护：范围震退和伤害、2 秒护盾、10 秒冷却 |

毅川保留“来了”“救命”“哦豁，完蛋”“坏啦”“怀不上了”等口头禅。开场、层间和结局串起公主救援剧情，第三层最终首领为杨梓亮。前两层首领具有弹幕、蓄力预警和狂暴阶段。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 俯视移动 |
| 空格 / Shift | 无敌冲刺 |
| E | NPC、补给、宝库、驿站、传送门 |
| Q | 哈少授予的洋葱守护 |
| Esc / Tab | 背包、合并、出售、暂停 / 返回 |
| 1–4 / R | 商店购买 / 刷新 |
| Enter / E | 推进对话 |
| F1 | 手册 |
| M / F11 | 静音 / 系统全屏切换 |
| Home | 暂停调试面板，1 无敌，2 一击必杀 |

启用过调试辅助的本局不写入普通纪录。

## 美术

角色、NPC、公主、首领、怪物、武器装备、墙门和地图道具均使用内置 **imagegen** 生成，并实际接入游戏。刀光、命中火花、魔法爆发、冲刺拖尾使用新生成的逐帧像素图集，弹丸、枪口火焰、护盾和蓄力预警也使用生成贴图；这些世界美术不再用矢量线条、圆环或多边形绘制。增加武器后坐与轻微命中镜头震动。新素材在 `assets/generated/dungeon/`；图集映射、生成提示词和限制见 `docs/dungeon-art.md`。中文和按钮由引擎绘制。
