# 毅川救我 · 地牢与像素旷野

v0.6.1 包含七层主题地牢与独立横版 2D 沙盒「像素旷野」。地牢穿过张江高科街道、需求办公室、霓虹机房、暗黑地牢、牛来的森林与草地、山田的相扑道场和策划城堡，救回 ChatGPT 公主。

沙盒复用地牢和早期横版的怪物资源，加入 19 类怪物、8 场 Boss、困难世界矿脉、住房与 NPC、远程与魔法、种植、钓鱼、水和熔岩。从砍树建家到最终救回 ChatGPT 公主，构成一条独立成长线。CTO 神父仍每 5 个游戏日到访，保留高难 Code Review 彩蛋。修复版补上地下床重生、住房去重与站位、幼苗掉落及重复 Boss 转阶段的问题。

## 运行

当前本地构建为 v0.6.1，EXE 可直接运行；ZIP 包含游戏、说明和许可文件。此前已发布版本：[v0.5.1 Windows 版](https://github.com/Biscuits-Lab/yichuan-save-me/releases/tag/v0.5.1)。

双击 `开始游戏.cmd`。启动脚本优先运行 `build/windows-v0.6.1/毅川救我.exe`，没有构建时使用项目内 Godot 运行源码。Windows 版资源内嵌，可独立运行，无需安装 Godot。便携包：`build/毅川救我-v0.6.1-地牢与沙盒-Windows-x64.zip`。

源码使用 Godot 4.5.2，打开 `project.godot` 后按 F5。缺少运行时可运行 `python tools/bootstrap.py`。

## 手柄操作

连接手柄或使用手柄时，菜单和 HUD 自动切换按键提示。使用键盘鼠标可切回对应提示。以下使用 Xbox 键名，识别到 PlayStation 或 Nintendo 手柄时显示其对应键名。

- 菜单用左摇杆或方向键移动焦点，A 确认，B 返回。
- 地牢用左摇杆移动，A 冲刺，X 交互，Y 使用洋葱守护，RB 部署炮塔，Start 打开背包，LB 打开指南。主菜单按 Y 进入沙盒。
- 沙盒用左摇杆移动，A 跳跃，右摇杆瞄准，RT 采掘或使用物品，LT 放置，LB / RB 切换物品。X 交互，Y 打开背包，Start 暂停。
- 支持双马达振动的手柄会对普通敌人击杀、受伤、死亡、Boss 蓄力、冲锋、震地、激光和击败首领播放不同的反馈。

## 沙盒模式 · 像素旷野

在主菜单点击「像素旷野 · 2D 沙盒生存」，或按键盘 B、Xbox 手柄 Y。首次创建随机世界，之后可继续独立沙盒存档。

- 576×192 格可编辑世界，每格 24 像素。森林、沙丘、雪原、丛林、版本侵蚀区、深层洞窟、熔火地狱与海岸；地下有三处带物资箱的遗迹，以及生命水晶、金矿、熔火矿和星辉矿。击败构建之墙后生成秘银。
- A / D、左右方向键移动；空格 / W / ↑ 跳跃。1 号镐长按鼠标左键挖掘，砍断树干可收集上方原木。数字键与滚轮切换快捷栏，选中方块后右键放置。背包里点击其他方块可装入当前快捷格。
- Tab / I 打开分页背包与四类制作；工作台 → 熔炉 → 铁砧 → 祭坛。采掘镐 → 铜 → 铁 → 金 → 熔火 → 秘银逐级解锁资源；制作需要实际放下设施并靠近。
- 木平台可向上跳穿、按 S 下穿；W / S 沿绳索攀爬。木门高两格，E 开关。住宅需封闭、内部至少 24 格、铺满背景墙，并有工作台、椅子、火把和门。F7 检查住房，满足成长条件后向导、若宇、海德骑士和嘉豪入住；床可设置重生点。
- E 开箱，材料可批量存入 / 全部取出，非空箱不可拆除。药草种子 60 秒成熟，树种 180 秒生长；桶可搬运水和熔岩，液体向下及两侧流动，相遇生成黑曜石。水下需注意氧气，熔岩会造成持续伤害。钓竿向水面左键抛竿，咬钩后再次左键，鲜鱼可在篝火旁烤制。
- J 挥剑，弓枪与法杖左键朝鼠标攻击，分别消耗弹药和魔力。11 种新武器包含长枪、巨斧、弓弩、手枪、霰弹枪、火 / 冰 / 过载法杖与召唤杖；6 套护甲和 5 件饰品提供防护、疾行、二段跳、Q 钩爪、飞行与熔岩减伤。生命水晶强化至 400、后期生命果至 500，魔力星强化至 200，另可叠加神父护符。
- H 优先使用强效药水，否则使用普通药水，药水共用 45 秒冷却；烤鱼提供短期再生。10 分钟一轮昼夜，每逢第 4 倍数游戏日的夜间有血色加班夜；可制作入侵旗挑战有限 24 只怪物。倒下可复活，保留背包和建筑。
- 击败怪物可获得凝胶与旧银币。神父在**游戏内第 5、10、15……天**来到出生地左侧，每次停留一个游戏日；暂停、背包、商店和 Code Review 不推进世界时间。神父采用《血源诅咒》加斯科因神父的猎人形象，身份栏显示 CTO。出售火把、药水、原木、煤炭、铜铁矿石、猎人提灯与神父护符。提灯扩大随身照明，护符增加 20 生命上限。每次到访补货，购买记录随世界保存，同次到访重开交易或读档不会补货。
- 神父购买界面提供 **Code Review** 彩蛋：20 张牌、10 组开发 Bug，限时 60 秒、最多 16 回合。全部配对显示「Code Review 通关」，可从货架免费任选 **1 个物品**。每次到访可领取一次，未领取的胜利资格随存档保留；已经拥有的唯一装备不能重复领，领取失败可以重试。
- M 查看带探索迷雾的地图，R 返回出生地，Esc 暂停，F1 查看指南，F5 保存。每 30 秒自动保存，退出前保存。沙盒使用 `user://sandbox-v1.save`，独立于地牢纪录；写入临时文件并保留一份滚动备份，主存档损坏时尝试恢复备份。当前提供一个世界槽，新建世界前有替换确认。
- 按 T 查看成长手册和怪物图鉴。Boss 顺序：故障凝胶王 → 风暴哨卫（夜间）→ 深渊大鲨鱼（侵蚀区）→ 地狱构建之墙（地狱，开启困难世界）→ 过载机械核心 → 荆棘母体（丛林）→ 山田横纲 → 杨梓亮终焉策划。用掉落升级装备并制作下一召唤物；可重复挑战补材料。归途信标是营地支线，最终战后救回公主，仍可自由建造。

本轮范围按「PC 单人核心玩法与完整成长流程」实现，采用本作世界观、地图尺度和怪物。它没有达到《泰拉瑞亚》全部内容的 1:1：原版完整 Boss / 物品 / 生物群系数量、电路自动化、入侵种类及联机不在当前实现内。具体功能、成长表与差异见 [沙盒扩充说明](docs/sandbox-adventure.md)，架构见 [sandbox-mode.md](docs/sandbox-mode.md)。

## 地牢模式玩法

- 战场铺满窗口，没有文字侧栏；右上角小地图透明无底板，用灰色表示未去过的房间、绿色表示已去过、金色表示当前房间，白点跟随角色位置。WASD / 方向键移动，武器自动瞄准攻击，空格 / Shift 无敌冲刺。
- 七层地牢分别生成 9、10、11、11、11、12、12 个房间，共 76 间，由一条通往 Boss 的主路与 2–3 条单房短支线组成，不生成环路。安全屋位于边界且只有一个出口，服务房有 30% 的机会出现在主路，其余情况出现在支线。普通怪物房为 800×544 到 1152×736，精英房为 1152×768，关底房为 1344×896；NPC 会客室为 416–480×288–352，其他服务房为 480–544×352–416，安全屋为 576×416。房间通过 176 像素宽的真实走廊连接，同层连续步行、镜头跟随、HUD 固定。
- 战斗房随机采用单波、双波或持续增援。前两层的三种模式概率分别为 70%、10%、20%，第三层起等概率。单波基础 14 只，双波基础 9／12 只，持续增援基础 20 只、分批到场。每升一层每波增加 2 只，每清 3 间战斗房再增加 1 只，清房加成上限 16 只。增援总量有限，仍有待生成敌人时不会开门；过密时排队生成。每层有自己的普通怪与精英，精英最后一波登场。进入战斗房内部才刷怪、封路，清空后自动拾取字节并弹出一次补给商店。关闭后不可返回，地图不生成补给入口；重返清房不会重新刷怪或发放补给。
- 普通远程怪和小绳头蓄力后一次发射三发扇形弹丸；七层关底首领各招式弹幕密度提高，保留原有攻击预警。怪物朝向随实际左右移动改变，停下蓄力时跟随已锁定攻击方向。
- 桌子、箱子、倒木等阻挡物被命中三次后碎成残骸，受损时出现错位和变色，碎裂后不再阻挡移动、寻路与攻击。同层返回房间保留破坏状态，换层和重开重置；服务设施与围墙不属于可破坏障碍。
- 普通波次混合追击史莱姆、远程怪、蓄力冲锋怪、快速突袭怪和分裂史莱姆。突袭怪短预警后快速冲刺；紫色大史莱姆死亡后分裂成三只更小、更快的史莱姆，小史莱姆不再分裂，全部击败才算完成本波。
- 击败每层关底首领后免费三选一提升技能，选择后进入下一层；最终首领选择后救回公主。战意、疾风、强健、再生、瞬身、洋葱守护分别强化伤害、攻速、生命、恢复、冲刺和 Q 守护，本局可叠加升级。
- 字节用于购买武器、装备、刷新货架和付费训练。累计字节与可花余额分别记录，出售不会刷高分。每局初始有 30 字节；右上角余额、商店与背包使用薄荷绿数据芯片图标，地面掉落也使用同一素材。
- 游商与清房补给的每轮货架都会从完整武器和道具池里抽四件不同商品。首刷免费，之后以 4、6、8…字节为基础递增，叠加清房和换层物价。补给开启期间可多次刷新与购买，也可打开背包整理。关闭后结束当次清房补给。
- 30 种武器，分近战、远程、魔法三类。新增电动订书枪、机械键盘锤、网线鞭、激光翻页笔、缺纸打印炮、扫描仪法灯、中央空调、消防演练喷筒、转椅旋风、门禁闸刀、电梯权限魔盒和白板擦爆弹。多武器同时自动攻击，每把独立冷却。
- 113 种道具，覆盖工位、会议、通勤和下班生活，例如已读不回、带薪拉屎、早高峰扶手、便利店关东煮和半夜猫砂铲。品质 I–IV 的道具属性倍率为 0.25 / 0.55 / 1 / 1.65，同名同品质自动叠加。背包每页最多 50 组，武器限六把。
- 携带「优先级全是 P0」或「护眼台灯」时，战斗中按 F 可在脚下部署其中一台。P0 警灯持续 7 秒，对附近敌人造成范围伤害，冷却 14 秒。护眼台灯持续 8 秒，自动向最近的可见敌人发射光束，冷却 15 秒。两种炮塔各自冷却，部署伤害按同类道具的最高持有品质计算。
- Esc / Tab 打开全屏背包并暂停。左侧显示武器和已获得的道具组，右侧显示带图标的角色属性、上限与技能。品质用底色和品质点表示，悬停或点击查看详情，右键合并或逐件出售，Esc 先关闭菜单。「返回标题」需要确认。两件同名同品质可合并一级，最高传说；武器满栏仍自动连续合并，装备拾取只叠加。武器无法接收时不扣字节、不消耗商品；至少保留一把武器。
- 所有难度初始生命均为 25。每成功清空一间普通、精英或首领房，基础物价增加 5%；每进入下一层，物价再乘 1.15（跨两层为 ×1.3225），商品和付费刷新同步涨价，清房补给与游商保留免费首刷。怪物生命每清房增加 10%、伤害增加 4%、移动速度增加 2%、攻击计时速度增加 2.5%；每升一层额外提高攻击计时速度 8%。成长跨层累计，重开归零；攻击预警时长保留。
- 每层等概率抽取一间咖啡驿站或 NPC 会客室。驿站可恢复 40 生命一次，游商仍可在 NPC 会客室出现。
- 房间与走廊入口不再绘制大门，战斗封路时仅显示小型贴图预警。地板和墙体按房间缓存并交给引擎剔除，角色、敌人和弹丸采用渲染插值，减少镜头移动时的跳帧感。
- 休闲 / 标准 / 硬核在开局前选择。倒下结束本局；重新开局重置字节、装备、技能和同伴，最高纪录保留。旧横版纪录不受影响。

- 武器按自己的伤害类型结算：对应类型攻击加成与通用伤害加成相加，最终总加成最多 +200%。例如键盘手托只增强近战，人体工学鼠标只增强远程，灵感便签只增强魔法；手枪不会吃到近战加成。
- 基础暴击率 5%、暴击伤害 150%、闪避 0%。上限：生命 200、减伤 65%、移速 352、攻速 +150%、暴击率 60%、暴击伤害 300%、闪避率 50%、恢复 3/秒、吸血 15%、攻击范围 +50%、拾取范围 280、冲刺恢复 +100%。单类专属攻击加成最多 +150%，与通用伤害合计仍受 +200% 限制。
- 风险道具同时生效收益与代价：玻璃心奖杯提高整体伤害并放大受伤，996 合同提高近战并降低减伤，通宵方案提高魔法并降低生命，超载公文包提高远程并降低攻速，三倍浓缩提高攻速并降低恢复，负重电脑包提高护甲并降低移速。负减伤会放大受伤；生命最低 5、攻速最低 0.35 倍、移速最低 132，易伤额外倍率最多 2 倍。出售后同步移除收益和代价。
- 击杀使用独立的短促弹性爆裂声，叠加清脆破裂瞬态和下坠的弹性低频，音量由 -12 dB 提高到 -6 dB；首领带更厚的低频尾音。声音有专用声道、轻微音高变化和 25 毫秒密集击杀限流，避免被连射声占满或同帧大量叠音。M 仍控制静音。

## NPC

每层抽到 NPC 会客室的概率为二分之一，抽到后从七位 NPC 中随机选择一位角色。战斗房、精英房和首领房不安排交互 NPC，清房后也不会出现；会客室禁止刷怪。接近 NPC 后按 E 交谈。海德骑士作为已招募战友可以同行战斗。

| NPC | 台词 | 服务 |
| --- | --- | --- |
| 罗德 | 给毅川派活 | 下一间战斗房追加一波，完成获得 45 字节，会客室保持安全 |
| 海德骑士 | 毅川救我 | 跟随当前层，自动近战；换房保留，换层离队 |
| 八桑 | 好他妈卡我草了 | 花 12 字节，本局武器伤害 +12% |
| 菈雅 | 这条路我熟，带上这个吧。 | 免费赠送随机武器或装备；满栏可自动合并，没有可接收物品时保留礼物 |
| 硬币 | 别赌运气，字节花在刀刃上。 | 出售可刷新的武器和装备 |
| 洋葱骑士哈少 | 学习学习 | 解锁 Q 洋葱守护：范围震退和伤害、2 秒护盾、10 秒冷却 |
| 嘉豪 | 装备到位，直接开干。 | 免费把一把携带武器提升一个品质，最高传说，每次偶遇一次 |

毅川保留“来了”“救命”“哦豁，完蛋”“坏啦”“怀不上了”等口头禅。开场、逐层剧情和结局串起公主救援，第七层最终首领为杨梓亮。七层首领基础生命分别为 1000／1750／2100／2400／2700／3000／3300，再叠加难度与清房成长。保安大爷轮换扇射、冲锋、震地与召援。需求守门人会工牌连射、举盾反击和标记落点。过载核心会四向电流与定点打击，若宇会扇射、点地、十字弹幕、拉拽和召援，半血进入摘眼镜演出，随后以无眼镜造型解封。牛来使用两连顶撞、踏地冲击和兽群召援，山田使用相扑冲锋、掌击和跺地。部分精英能拉拽玩家或在举盾时降低正面伤害。精英基础生命为 600／1000／1300／1600／1900／2200／2500。森林与草地保持豹拉、黑狼和小绳头的原阵容与招式。

- 第 4 层为暗黑地牢，主路依次经过网吧、小区内部和客厅，关底房为若宇的卧室。若宇从会客室移至关底，战斗中通过角色身侧的气泡轮换五句台词。半血时暂停战斗播放摘眼镜演出，解封后以高伤害飞扑开场。飞扑会先标记落点，触地后若宇倒地、爬起并露出反击空档。
- 第 7 层杨梓亮先开盾召唤关卡策划林宇、TA 林逸枫和三只城堡小怪。清完召援后他破盾跪地 1.2 秒，随后起身用列阵还击。生命降到一半时换上红镜片和深色长外套，进入巅峰。二阶段轮换列阵、十字弹幕、标记、召援和眼镜激光，各有独立的蓄力及出招姿势。激光锁定方向后预警 0.95 秒，横移可躲开。

## 地牢美术

角色、NPC、公主、首领、怪物、武器装备、墙体和地图道具均使用内置 **imagegen** 生成，并实际接入游戏。刀光、命中火花、魔法爆发、冲刺拖尾使用逐帧像素图集，弹丸、枪口火焰、护盾和蓄力预警也使用生成贴图；这些世界美术不使用矢量线条、圆环或多边形绘制。新增 51 个独立透明物品缩略图，由内置 imagegen 绘制；正式资源在 `assets/generated/dungeon/icons/`，源图和完整提示词分别保存在同目录上层与 `docs/office-icons-imagegen-prompts.json`。武器带后坐与轻微命中镜头震动。办公桌采用固定尺寸并保持原图比例，大型摆放使用多张桌子组合。入口不再绘制大门。素材在 `assets/generated/dungeon/`；图集映射、生成提示词和限制见 `docs/dungeon-art.md`。中文和按钮由引擎绘制。

## 音乐

七层各有独立的原创循环 BGM。张江高科使用机械节奏，办公室为轻快电钢琴，霓虹机房为电子合成器，暗黑地牢为空灵钟音与氛围铺底，森林草地为木笛、拨弦与手鼓，道场为筝音与太鼓，城堡为管风琴、弦乐与进行曲。每首约 27–37 秒，切关时交叉淡入淡出，同层换房不重播；M 静音继续生效。

音频位于 `assets/audio/music/`，由本地合成生成，无外部采样。需要修改曲谱并重新生成时运行 `python tools/compose_floor_music.py`（生成工具需要 FFmpeg，游玩无需安装）。

沙盒复用毅川、怪物、NPC 与武器装备图集；方块、基础资源图标与远景使用代码生成的像素贴图，神父使用新增的 imagegen 透明立绘。提示词与实现说明见 `docs/sandbox-mode.md`。
