# 毅川救我 · 地牢与像素旷野

v0.5.1 包含七层主题地牢与独立的横版 2D 沙盒「像素旷野」。地牢穿过办公室、工坊、霓虹机房、温室、牛来的森林与草地、山田的相扑道场和策划城堡，救回 ChatGPT 公主；沙盒提供随机世界、挖矿建造、采集制作、昼夜生存，以及每 5 个游戏日到访的 CTO 神父与高难 Code Review 翻牌小游戏。

## 运行

下载：[v0.5.1 Windows 版](https://github.com/Biscuits-Lab/yichuan-save-me/releases/tag/v0.5.1)。EXE 可直接运行；ZIP 包含游戏、说明和许可文件。

双击 `开始游戏.cmd`。启动脚本优先运行 `build/windows-v0.5.1/毅川救我.exe`，没有构建时使用项目内 Godot 运行源码。Windows 版资源内嵌，可独立运行，无需安装 Godot。便携包：`build/毅川救我-v0.5.1-地牢与沙盒-Windows-x64.zip`。

源码使用 Godot 4.5.2，打开 `project.godot` 后按 F5。缺少运行时可运行 `python tools/bootstrap.py`。

## 沙盒模式 · 像素旷野

在主菜单点击「像素旷野 · 2D 沙盒生存」，或按 B。首次创建随机世界，之后可继续独立沙盒存档。

- 576×192 格可编辑世界，每格 24 像素。森林、沙丘、雪原、随机洞穴、铜铁煤矿与深层水晶；出生地右侧有通向地下的洞口。
- A / D、左右方向键移动；空格 / W / ↑ 跳跃。1 号镐长按鼠标左键挖掘，砍断树干可收集上方原木。数字键与滚轮切换快捷栏，选中方块后右键放置。背包里点击其他方块可装入当前快捷格。
- Tab / I 打开背包与制作；E 与附近神父交易，其他位置打开制作。先用 8 原木制作工作台，放在地上，再靠近制作熔炉。熔炉消耗矿石与煤炭生成铜锭、铁锭。基础镐 → 铜镐 → 铁镐依次解锁铁矿、水晶与大地之心。
- J 随时挥剑，选中 2 号剑也可长按左键攻击；H 消耗治疗药水恢复 45 生命。10 分钟一轮昼夜，夜间与地下怪物更强。火把提供照明。倒下可复活，保留背包和建筑。
- 击败怪物可获得凝胶与旧银币。神父在**游戏内第 5、10、15……天**来到出生地左侧，每次停留一个游戏日；暂停、背包、商店和 Code Review 不推进世界时间。神父采用《血源诅咒》加斯科因神父的猎人形象，身份栏显示 CTO。出售火把、药水、原木、煤炭、铜铁矿石、猎人提灯与神父护符。提灯扩大随身照明，护符增加 20 生命上限。每次到访补货，购买记录随世界保存，同次到访重开交易或读档不会补货。
- 神父购买界面提供 **Code Review** 彩蛋：20 张牌、10 组开发 Bug，限时 60 秒、最多 16 回合。全部配对显示「Code Review 通关」，可从货架免费任选 **1 个物品**。每次到访可领取一次，未领取的胜利资格随存档保留；已经拥有的唯一装备不能重复领，领取失败可以重试。
- M 查看带探索迷雾的地图，R 返回出生地，Esc 暂停，F1 查看指南，F5 保存。每 30 秒自动保存，退出前保存。沙盒使用 `user://sandbox-v1.save`，独立于地牢纪录；写入临时文件并保留一份滚动备份，主存档损坏时尝试恢复备份。当前提供一个世界槽，新建世界前有替换确认。
- 收集深处的大地之心、12 水晶与 4 铁锭，在工作台旁制作归途信标，放在地表完成探索；之后可以继续建造。

这是沙盒首版，包含采集、制作、建造与生存循环；暂不包含液体流动、联网、NPC 住房、农业或泰拉瑞亚的完整 Boss 体系。架构、资源与验证说明见 [docs/sandbox-mode.md](docs/sandbox-mode.md)。

## 地牢模式玩法

- 战场铺满窗口，没有文字侧栏；右上角小地图透明无底板，用灰色表示未去过的房间、绿色表示已去过、金色表示当前房间，白点跟随角色位置。WASD / 方向键移动，武器自动瞄准攻击，空格 / Shift 无敌冲刺。
- 七层地牢分别生成 10、11、12、13、14、15、16 个房间，共 91 间，由一条通往 Boss 的主路与 3–4 条单房短支线组成，不生成环路；安全屋位于边界且只有一个出口，服务房和宝库放在支线。普通怪物房为 800×544 到 1152×736，精英房为 1152×768，关底房为 1344×896；NPC 会客室为 416–480×288–352，其他服务房为 480–544×352–416，安全屋为 576×416。房间通过 176 像素宽的真实走廊连接，同层连续步行、镜头跟随、HUD 固定。七层分别为办公室、工坊、霓虹机房、失控温室、森林与草地、相扑道场和城堡。
- 战斗房随机采用单波、双波或持续增援。单波基础 18 只，双波基础 12／16 只，持续增援基础 28 只、分批到场；每升一层额外增加 4 只，每成功清房额外增加 1 只。增援总量有限，仍有待生成敌人时不会开门；过密时排队生成。精英房最后由大鲨鱼、孵化母体或风暴哨卫随机守关，分别擅长冲锋、召唤与弹幕。进入战斗房内部才刷怪、封路，清空后自动拾取字节并弹出一次补给商店。关闭后不可返回，地图不生成补给入口；重返清房不会重新刷怪或发放补给。
- 普通远程怪和小绳头蓄力后一次发射三发扇形弹丸；七层关底首领各招式弹幕密度提高，保留原有攻击预警。怪物朝向随实际左右移动改变，停下蓄力时跟随已锁定攻击方向。
- 桌子、箱子、倒木等阻挡物被命中三次后碎成残骸，受损时出现错位和变色，碎裂后不再阻挡移动、寻路与攻击。同层返回房间保留破坏状态，换层和重开重置；宝箱、服务设施与围墙不属于可破坏障碍。
- 普通波次混合追击史莱姆、远程怪、蓄力冲锋怪、快速突袭怪和分裂史莱姆。突袭怪短预警后快速冲刺；紫色大史莱姆死亡后分裂成三只更小、更快的史莱姆，小史莱姆不再分裂，全部击败才算完成本波。
- 击败每层关底首领后免费三选一提升技能，选择后进入下一层；最终首领选择后救回公主。战意、疾风、强健、再生、瞬身、洋葱守护分别强化伤害、攻速、生命、恢复、冲刺和 Q 守护，本局可叠加升级。
- 字节用于购买武器、装备、刷新货架和付费训练。累计字节与可花余额分别记录，出售不会刷高分。每局初始有 30 字节；右上角余额、商店与背包使用薄荷绿数据芯片图标，地面掉落也使用同一素材。
- 商店每轮从完整武器与道具池随机抽取四件不同商品，不固定武器和道具数量，也不保送当前武器。清房补给仅提供这一批商品，不可刷新，退出后不可返回，期间可打开背包整理。独立商店房与游商可反复访问并保留货架，仍可手动刷新；首次免费，之后以 4、6、8…字节为基础，叠加清房和换层物价。
- 18 种武器，分近战、远程、魔法三类：原六种之外加入美工刀、巨斧、粉碎锤、签字钢笔、冲锋枪、重弩、狙击枪、摸鱼左轮、飞旋工牌、火杖、冰杖、轨道炮。具有不同射速、范围、贯穿、扇射、爆炸、减速和暴击特性；多武器同时自动攻击，每把独立冷却。
- 39 种上班主题道具，包括护肝片、健康餐、蜜雪冰城、双倍浓缩、人体工学椅，以及三种攻击流派的专用道具。普通 / 精良 / 史诗 / 传说道具的增益为原普通数值的 25% / 55% / 100% / 165%，第三级才达到原普通增益；武器品质伤害成长保持原规则。道具数量无限，同名同品质自动叠加，所有属性均有上限。战斗 HUD 隐藏底部武器和道具栏，统一在背包查看；背包每页 12 组，武器仍限六把。
- Esc / Tab 打开 832×520 背包并暂停，物品格缩为 64×64 正方形；背包与角色属性分为独立页签，属性页显示实际属性、上限和已学技能。品质用底色和品质点表示，悬停或点击查看名称、品质、实际属性和售价，负面属性标红；右键菜单提供合并与逐件出售，Esc 先关闭菜单。两件同名同品质可合并一级，最高传说；武器满栏仍自动连续合并，装备拾取只叠加。武器无法接收时不扣字节、不消耗商品；至少保留一把武器。
- 所有难度初始生命均为 25。每成功清空一间普通、精英或首领房，基础物价增加 5%；每进入下一层，物价再乘 1.15（跨两层为 ×1.3225），商品与独立商店、游商的付费刷新同步生效，这两类商店保留免费首刷。怪物生命每清房增加 10%、伤害增加 4%、移动速度增加 2%、攻击计时速度增加 2.5%；每升一层额外提高攻击计时速度 8%。成长跨层累计，重开归零；攻击预警时长保留，专用商店房在涨价后打 85 折。
- 每层 NPC 房与商店房合计随机生成 0–1 间，独立商店房全场 85 折。宝库打开后显示两张精良武器卡和一张精良装备卡，选择一件才装备，也可放弃；两种操作均每箱一次，武器栏满时可先打开背包整理。驿站每房恢复 40 生命一次。宝箱和休息点进入视野就会显示，无需先进入房间。
- 房间与走廊入口不再绘制大门，战斗封路时仅显示小型贴图预警。地板和墙体按房间缓存并交给引擎剔除，角色、敌人和弹丸采用渲染插值，减少镜头移动时的跳帧感。
- 休闲 / 标准 / 硬核在开局前选择。倒下结束本局；重新开局重置字节、装备、技能和同伴，最高纪录保留。旧横版纪录不受影响。

- 武器按自己的伤害类型结算：对应类型攻击加成与通用伤害加成相加，最终总加成最多 +200%。例如键盘手托只增强近战，人体工学鼠标只增强远程，灵感便签只增强魔法；手枪不会吃到近战加成。
- 基础暴击率 5%、暴击伤害 150%、闪避 0%。上限：生命 200、减伤 65%、移速 352、攻速 +150%、暴击率 60%、暴击伤害 300%、闪避率 50%、恢复 3/秒、吸血 15%、攻击范围 +50%、拾取范围 280、冲刺恢复 +100%。单类专属攻击加成最多 +150%，与通用伤害合计仍受 +200% 限制。
- 风险道具同时生效收益与代价：玻璃心奖杯提高整体伤害并放大受伤，996 合同提高近战并降低减伤，通宵方案提高魔法并降低生命，超载公文包提高远程并降低攻速，三倍浓缩提高攻速并降低恢复，负重电脑包提高护甲并降低移速。负减伤会放大受伤；生命最低 5、攻速最低 0.35 倍、移速最低 132，易伤额外倍率最多 2 倍。出售后同步移除收益和代价。
- 击杀使用独立的短促弹性爆裂声，叠加清脆破裂瞬态和下坠的弹性低频，音量由 -12 dB 提高到 -6 dB；首领带更厚的低频尾音。声音有专用声道、轻微音高变化和 25 毫秒密集击杀限流，避免被连射声占满或同帧大量叠音。M 仍控制静音。

## NPC

每层 NPC 会客室与商店房合计最多一间，也可能没有；出现 NPC 会客室时，从八位 NPC 中随机选择一位角色。战斗房、精英房和首领房不安排交互 NPC，清房后也不会出现；会客室禁止刷怪。接近 NPC 后按 E 交谈。海德骑士作为已招募战友可以同行战斗。

## 地牢美术

角色、NPC、公主、首领、怪物、武器装备、墙体和地图道具均使用内置 **imagegen** 生成，并实际接入游戏。刀光、命中火花、魔法爆发、冲刺拖尾使用逐帧像素图集，弹丸、枪口火焰、护盾和蓄力预警也使用生成贴图；这些世界美术不使用矢量线条、圆环或多边形绘制。新增 51 个独立透明物品缩略图，由内置 imagegen 绘制；正式资源在 `assets/generated/dungeon/icons/`，源图和完整提示词分别保存在同目录上层与 `docs/office-icons-imagegen-prompts.json`。武器带后坐与轻微命中镜头震动。办公桌采用固定尺寸并保持原图比例，大型摆放使用多张桌子组合。入口不再绘制大门。素材在 `assets/generated/dungeon/`；图集映射、生成提示词和限制见 `docs/dungeon-art.md`。中文和按钮由引擎绘制。

## 音乐

七层各有独立的原创循环 BGM：办公室为轻快电钢琴，工坊为金属敲击与机械节奏，霓虹机房为电子合成器，温室为空灵钟音与氛围铺底，森林草地为木笛、拨弦与手鼓，道场为筝音与太鼓，城堡为管风琴、弦乐与进行曲。每首约 27–37 秒，切关时交叉淡入淡出，同层换房不重播；M 静音继续生效。

音频位于 `assets/audio/music/`，由本地合成生成，无外部采样。需要修改曲谱并重新生成时运行 `python tools/compose_floor_music.py`（生成工具需要 FFmpeg，游玩无需安装）。

沙盒复用毅川和怪物图集；方块、物品图标与远景使用代码生成的像素贴图，神父使用新增的 imagegen 透明立绘。提示词与实现说明见 `docs/sandbox-mode.md`。
