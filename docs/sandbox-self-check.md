# 沙盒自检与修复 · v0.5.1

本轮在 v0.5.0 工作区上补充异常场景、实际输入和小游戏检查，并按最新设定将神父改为五个游戏日一次到访，身份栏保留 CTO，加入高难 Code Review。

## 已复现并修复

| 问题 | 修复后的行为 |
| --- | --- |
| 新建世界确认框仍保留底层菜单按钮，能点击穿透 | 仅确认与取消两个按钮可响应 |
| 从备份恢复后再次保存，会把损坏主档复制覆盖有效备份 | 只备份通过完整校验的主档，保留可恢复副本 |
| 出生点或神父脚下被挖成竖井，定位优先选中井底 | 根据距原地表的位置选择附近安全站立点 |
| 死亡后保存并读取，只恢复 1 点生命 | 按正常复活恢复生命，保留背包与地形 |
| 交易保存失败仍扣款、发货并返回成功 | 回滚货币、物品与库存，允许重试 |
| 异常字段可进入数值转换或状态赋值 | 应用前校验字段类型、范围、库存、快捷栏与奖励状态 |
| 输入注入时鼠标点击位置与全局鼠标查询不一致 | 按事件坐标处理按钮、挖掘和放置，统一指针来源 |
| 日期显示到上午才加一天 | 在游戏内午夜换日 |
| 方块可以埋住神父或敌人 | 实体方块不能与活动角色的碰撞范围重叠 |
| 恢复地形后可能沿用旧的商人位置缓存 | 读取地形时增加修订号，重新计算安全位置 |
| 模式菜单看不到读档错误提示 | 菜单和游戏内均显示操作失败原因 |
| Windows 启动脚本的中文 EXE 路径依赖系统代码页 | 在读取中文路径前切换到 UTF-8 |

最初的定向复现运行有 13 个断言，其中 8 个失败，证明旧检查遗漏了上述部分问题；修复后的回归集已扩展到 67 项。

## 新设定与彩蛋

神父在游戏内第 5、10、15……天到访，停留一天。暂停、背包、商店和 Review 不推进世界时间。旧版现实日期存档兼容读取，世界与物品保留，商人使用新的到访规则。

Code Review 为 20 张牌、10 组、60 秒、16 回合；最多配错 6 次。检查覆盖错配展示、禁翻第三张、牌不能匹配自身、超时、回合耗尽、最后一个允许回合获胜、重新挑战、世界暂停、通关和鼠标操作入口。免费奖励每次到访领取一次，不能重复领唯一装备；待领取资格可读档恢复，保存失败不丢资格。
