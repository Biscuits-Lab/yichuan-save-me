# v0.4.5 俯视角美术

本轮全部使用 Codex 内置 **image_gen** 工具生成。未使用 CLI / API 回退；PNG 已复制到项目，运行时直接读取原始图集，不依赖 Codex 的生成目录。透明背景修复也使用 image_gen。图集裁切和缩放由 Godot 渲染完成，不重写源图像。

统一方向：16 位像素、靛蓝描边、薄荷与琥珀高光、三头身角色、从上方观察的三分之四视角。角色四向移动，场景在同一平面，没有横版跳跃与地平线。

`environment-source.png` 是最初的森林场景生成稿；`environment.png` 是使用 image_gen 修复透明背景后的稿件。随后按用户要求，将第一层地面与两种道具改为办公室风格，得到实际使用的 `environment-office.png`。两份过程稿保留作追溯，不打入 Windows 成品。

第一层办公室包含电脑工位、隔断、键盘、绿植、椅子和咖啡。场景装饰与实际障碍分开，碰撞及寻路使用统一的地面矩形。所有房间出口保留宽敞通路，墙体、弹丸、冲刺、刀光、命中、护盾和蓄力预警均使用 imagegen 像素贴图。入口大门已移除，战斗封路仅显示小型贴图预警。数字、菜单和血条仍由引擎界面绘制。

## 提示词

- 初次五套图集完整提示词：`dungeon-imagegen-prompts.json`。
- 办公室修改完整提示词：`dungeon-office-imagegen-prompt.txt`。
- 环境透明修复提示词：保留 4×3 网格、尺寸与所有物体，只将第二、三行道具外白色及半透明背景改为 alpha=0，保持第一行四个地面为不透明，不改动道具内部白色高光。

## 验证与限制

十套实际使用图集均通过运行时加载及格数检查；已检查标题、剧情、办公室战斗、商店、融合背包、NPC、最终首领和结局的引擎截图。角色使用统一图集根锚点；武器在世界中与菜单中使用同一套生成素材。

图集动画为生成式四帧循环，局部姿态仍有细节差异；道具高光可能在极小尺寸下丢失。战斗平衡和长期手感仍需要实际试玩打磨。

## 连续地牢与战斗特效

本轮新增两张内置 imagegen 图集，完整生成提示词保存于 `dungeon-vfx-imagegen-prompts.json`：

| 文件，位于 `assets/generated/dungeon/` | 网格 | 内容 |
| --- | --- | --- |
| `combat-vfx.png` | 4×4 | 每行四帧动画：薄荷刀光、金色命中火花、紫色法术爆发、青色冲刺拖尾 |
| `dungeon-utility.png` | 4×4 | 第一行：友方子弹、敌方法弹、像素落地影、枪口火焰；第二行：蓄力箭头、护盾、传送门、积分币；第三行：横墙、竖墙、墙角柱、关闭的门；第四行：打开的门、需求文档弹、灰尘、增益闪光 |

世界绘制使用图集帧和贴图变换，不以矢量图形替代特效。四帧特效沿相同格子中心播放，保留展开及消散过程；子弹和枪口按攻击方向旋转，武器带后坐偏移，受伤保留可见剪影。

地图每层 NPC 会客室与商店房合计随机 0–1 间，其余普通房间以战斗为主；每间怪物房清空后打开补给，入口不提供商店终端。战斗房没有交互 NPC。大小房间使用世界坐标，通过可行走的走廊相接；Camera2D 跟随角色，CanvasLayer 固定 HUD。地板、墙体与固定装饰按房间、走廊保留绘制命令，由引擎剔除镜头外的节点；动态角色与弹丸插值显示，HUD 降低重绘频率并复用面板样式。

## 八桑与哈少更新

八桑使用内置 imagegen 新生成的独立双姿态像素图集 `assets/generated/dungeon/basan.png`，在地图与对话中都替换旧忍者造型；其他 NPC 继续使用原图集。训练服务及原台词保留，洋葱骑士哈少的口头禅改为“学习学习”。本轮生成提示词保存在 `basan-imagegen-prompt.txt`。

## 嘉豪与大鲨鱼

嘉豪加入稀有 NPC 房的随机人选池，仍遵守每层 NPC／商店合计 0–1 间。他可免费把一把装备中的武器提升一个品质；全部传说时不消耗服务。大鲨鱼作为精英房最后一波的独立首领，具有蓄力预警、实体冲锋、扇形弹幕和半血狂暴；击败后只清空精英房，不触发主线结局。新增角色使用内置 imagegen，完整提示词位于 `jiahao-shark-imagegen-prompts.json`。

NPC 会客室缩小为宽 512–576、高 352–416 的安全小房间，保留四向走廊开口与交谈空间。

## 商店与场景修正

普通怪物房与精英房清空后自动打开补给；不会额外生成随机商店房。每轮两张武器、两张装备卡，刷新后保证货架变化。首刷免费，之后按 4、6、8…积分递增，同一房间重新打开保留进度。关底首领清空后改为免费三选一技能升级，技能卡复用已有武器装备插画；选择后进入下一层，最终首领选择后进入结局。

办公桌碰撞占地固定为 96×56，房间变大只改变摆放间距，较长区域用多桌组合；所有家具贴图均匀缩放并保持原图长宽比。按用户要求已移除大门造型；`upright-doors.png` 与 `upright-doors-imagegen-prompt.txt` 保留作生成过程追溯，不再加载或导出。
