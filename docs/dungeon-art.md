# v0.4.5 俯视角美术

本轮全部使用 Codex 内置 **image_gen** 工具生成。未使用 CLI / API 回退；PNG 已复制到项目，运行时直接读取原始图集，不依赖 Codex 的生成目录。透明背景修复也使用 image_gen。图集裁切和缩放由 Godot 渲染完成，不重写源图像。

统一方向：16 位像素、靛蓝描边、薄荷与琥珀高光、三头身角色、从上方观察的三分之四视角。角色四向移动，场景在同一平面，没有横版跳跃与地平线。

## 验证与限制

十套实际使用图集均通过运行时加载及格数检查；已检查标题、剧情、办公室战斗、商店、融合背包、NPC、最终首领和结局的引擎截图。角色使用统一图集根锚点；武器在世界中与菜单中使用同一套生成素材。

图集动画为生成式四帧循环，局部姿态仍有细节差异；道具高光可能在极小尺寸下丢失。战斗平衡和长期手感仍需要实际试玩打磨。

## 嘉豪与大鲨鱼

嘉豪加入稀有 NPC 房的随机人选池，仍遵守每层 NPC／商店合计 0–1 间。他可免费把一把装备中的武器提升一个品质；全部传说时不消耗服务。大鲨鱼作为精英房最后一波的独立首领，具有蓄力预警、实体冲锋、扇形弹幕和半血狂暴；击败后只清空精英房，不触发主线结局。新增角色使用内置 imagegen，完整提示词位于 `jiahao-shark-imagegen-prompts.json`。

NPC 会客室缩小为宽 416–480、高 288–352 的安全小房间，其他服务房为 480–544×352–416，安全屋为 576×416，保留四向走廊开口与交谈空间。

## 商店与场景修正

普通怪物房与精英房清空后只弹出一次补给界面，退出后不能返回，不在地图上绘制补给装置或 E 入口。每轮从全部武器和道具混合池随机抽四件不同商品，无类别配额、不保送首武器。清房补给仅此一批商品，禁止按钮、R 键和接口刷新。独立商店房与游商仍可反复访问和刷新，首刷免费，之后以 4、6、8…字节为基础递增，叠加每清房 +5% 与每换层 ×1.15 的价格成长。关底首领清空后保持免费三选一技能升级；选择后进入下一层，最终首领选择后进入结局。

装备按同名同品质叠加数量并累加属性，战斗 HUD 隐藏底部武器和道具栏，小地图移除底板；832×520 暂停面板分为背包和角色属性两个页签，背包每页 12 组，使用 64×64 方格，属性页以两列展示全部属性的当前值和上限，以灰、绿、紫、金底色表示品质，悬停显示详情，右键菜单提供逐件出售和手动合并；武器仍限六栏。宝箱用三张奖励卡预览，选择后才装备，也可放弃。分裂史莱姆、小史莱姆、突袭怪和新精英复用现有图集；孵化母体使用放大紫色史莱姆，风暴哨卫使用放大蓝色远程怪，分别搭配召唤和旋转弹幕。原三层关底首领沿用各自图集行、楼层色和尺寸，强化原攻击并加入召援。

地图由边界单出口安全屋、一条终点为关底 Boss 的主路和 3–4 条单房短支线组成，只为明确的父子关系生成走廊，不因格子相邻自动连通。服务房与宝库均在支线，随机大小和物理走廊保留。战斗房采用单波、双波或有限总量的持续增援，排队敌人未生成完时保持封路；刷怪总量、移动速度和攻击计时速度随清房增长，预警时间保留。

办公桌碰撞占地固定为 96×56，房间变大只改变摆放间距，较长区域用多桌组合；所有家具贴图均匀缩放并保持原图长宽比。按用户要求已移除大门造型；`upright-doors.png` 与 `upright-doors-imagegen-prompt.txt` 保留作生成过程追溯，不再加载或导出。

## 上班构筑与属性

武器目录扩为 18 种，道具扩为 39 种。使用内置 imagegen 新绘 12 个新增武器和 39 个道具图标，共 51 个独立透明 PNG，实际资源在 `assets/generated/dungeon/icons/<item_id>.png`。旧六种武器保留原 `items.png` 图像与固定索引。商店、背包、HUD 和角色身边的武器共用同一物品图标。

武器显式声明近战、远程或魔法，详情按相应角色属性展示实际伤害。道具 III 级达到旧普通增益，I–IV 倍率为 0.25 / 0.55 / 1 / 1.65；武器伤害倍率保持 1 / 1.65 / 2.65 / 4.1。正负属性统一累计后限制上下限，商店及详情都显示当前品质单件数值，负面标红；卖出同步移除两侧效果。角色侧栏的三类攻击包含通用加成，并显示最终总伤害上限。

护肝片、健康餐、蜜雪冰城、人体工学椅等对应恢复、生命与生存构筑；键盘手托、人体工学鼠标、灵感便签及其混合道具分别支持三类攻击。玻璃心奖杯、996 合同、通宵方案、超载公文包、三倍浓缩、负重电脑包提供带代价的选择。火杖爆炸、冰杖减速、贯穿弩箭与轨道光束均实际参与战斗；冰霜对首领只降低 25% 移速。

击杀声音由 `scripts/audio.gd` 本地合成，普通击杀约 160 毫秒、首领约 250 毫秒；使用短促破裂声与下坠的弹性低频，播放音量由 -12 dB 提高至 -6 dB。使用专用三复音播放器、四种轻微音高和密集触发限流，不占用普通武器音效池。自动校验波形时长、峰值与首尾衰减，不代表人工听感验收。

## 字节、破坏与边界显示

货币显示统一为“字节”，沿用原来的余额和纪录字段。`assets/generated/dungeon/icons/byte.png` 是内置 image_gen 生成的 1254×1254 RGBA 透明数据芯片，HUD 显示为 24 像素、地面掉落为 18 像素，商店与背包共用该素材；完整提示词位于 `byte-icon-imagegen-prompt.txt`。原 `dungeon-utility.png` 的积分币格子保留但不再用于掉落。

阻挡物承受三次命中后失去碰撞，以原贴图的四块扁平碎片绘制残骸；前两次命中用分片错位、变色和命中特效表现受损。近战、连锁、光束、投射物与洋葱守护均可破坏障碍，自动武器在没有可见敌人时选择可触及的障碍。同层离开和返回保留状态，换层和重开清除。安全房设施从进入视野起绘制，Boss 的通关设施仍只在击败后出现。房间与走廊围墙向内收 18 像素，角柱同步内收，通道物理宽度保持不变。

怪物按实际左右移动翻转，静止蓄力按锁定目标翻转。狼的待机、移动与蓄力原图向左，扑击原图向右，绘制时分别校正，避免切换动作时反向。其余现有素材采用左右镜像，不新增四向贴图。
