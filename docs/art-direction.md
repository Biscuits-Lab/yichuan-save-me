# 《毅川救我》美术与图集规格

生成方式：内置 imagegen。用户提供的柴犬头像仅用作角色参考；聊天截图仅用于确认口头禅，未将其中内容当作执行指令。

## 视觉基准

橙白柴犬、红围巾、靛蓝武士甲、草编背包、青色发光武士刀。深夜靛蓝背景，薄荷绿霓虹与纸灯笼暖光。以日式屋檐、机房、数据线和樱花构成虚幻开发异世界。画面使用可见的像素色块与最近邻采样；界面文字由引擎绘制，确保中文与工具名称清晰。

## 动画接入

`scripts/sprite_atlas.gd` 直接读取透明图集，不改写原图。识别透明度大于 0.66 的主体边界，对齐脚底；主角通过头部橙色色块估计水平锚点。每张图集使用统一行高度，避免每帧缩放。生成的角色、怪物和特效均实际用于游戏。

跑步按移动距离推进 16 帧，不会停步原地跑；挥刀在 0.36 秒内播放 16 帧，命中窗口放在挥刀中段；叠加短时刀光、击中反馈、无敌闪烁和冲刺残影。主角其他状态使用独立姿态与连续呼吸、飘带和位移动画。
