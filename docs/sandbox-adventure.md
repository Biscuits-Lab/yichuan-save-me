# 像素旷野成长扩充 · v0.6.1

## 范围与背景

本轮确认的范围是 **PC 单人核心玩法与完整成长流程**。以采集、建家、装备、探索、Boss 解锁、困难世界、最终战构成可完成的成长线；复用本项目肉鸽和早期横版的资源，故事继续围绕毅川救回被策划杨梓亮带走的 ChatGPT 公主。CTO 神父的五游戏日到访及高难 Code Review 保留原规则。

参考的是《泰拉瑞亚》的核心循环与分阶段成长，见官方社区 Wiki 的 [成长指南](https://terraria.wiki.gg/wiki/Guide%3AGame_progression)、[新手指南](https://terraria.wiki.gg/wiki/Guide%3AGetting_started) 和 [困难模式](https://terraria.wiki.gg/wiki/Hardmode)。实际实现使用本作角色、数值、八场成长战役和固定有限世界，不声称达到原作所有内容的 1:1。

## 核心循环

1. 砍树、采石，制作工作台、熔炉和铁砧；熔炼铜铁，升级工具。
2. 采生命水晶、收集辉光水晶、开启地下遗迹箱子；建造住宅及战斗平台，准备护甲、弹药、药水和饰品。
3. 建造召唤祭坛，制作召唤物。Boss 前置、区域及昼夜条件都在实际召唤时校验，失败不扣召唤物。
4. 击败 Boss 获取专属材料，制作下一矿级的工具和装备；可重打补足不同流派的材料。
5. 地狱构建之墙后开启困难世界，生成秘银矿，普通敌人生命 ×1.8、伤害 ×1.3，并扩充刷新池。
6. 最终击败杨梓亮，出现救回公主的结局，世界继续开放。原来的归途信标改为营地支线。

## 怪物资源复用

地牢的史莱姆、分裂体、冲锋虫、突袭者、远程怪，森林的狼与小绳头，以及大鲨鱼、山田、哨卫、母体和策划图集用于本模式。早期横版的 `engine-enemies.png` 和 `engine-enemies-expanded.png` 则提供同步甲虫、空引用幽灵、版本盾卫、编译火灵、浮空构造体、流明灯蛾、缓存拟态箱、回收菌怪、泄漏孢子、热重载猎手与延迟飞灵。

十九类普通怪物按区域、昼夜与成长阶段组合刷新。它们具有跳跃追击、冲锋、扑击、扇形弹幕、飞行、正面护盾、地面预警、环射和死亡分裂等行为，不只是替换原史莱姆的贴图。早期横版图集已加入 Windows 导出范围。

## 存档与实现

继续使用 `sandbox-v1.save`，以可选的 `adventure` 字段兼容旧存档。新增 Boss、图鉴、护甲、饰品、生命与魔力强化、食物与药水冷却、入侵进度、背景墙、液体、箱子、植物和门数据。读取前验证类型、尺寸、范围、前置顺序及有限数值。旧档保留原建筑；只在未探索区域补充矿物，不挖开已探索地形。

## 验证边界与原作差异

自动验证覆盖八个阶段的合法召唤、前置拒绝、警告后攻击、掉落、制作、困难世界和最终结局。成长测试注入基础材料并用测试伤害击败 Boss，以隔离验证规则；**不等于人工从零游玩通关，也不能证明最终战斗平衡**。另用实际怪物、投射物、碰撞和 3600 次物理步进检查持续运行；实机渲染和鼠标交互单独验证。

这是一条可以从开局走到结局的本作成长线。与原作仍有明确差异：世界尺寸固定；Boss、物品、生物群系、住房规则及事件采用本作的有限集合；没有原版全部 Boss 分支、全套生态传播、电路自动化、液体压力/蜂蜜、钓鱼任务和联机。沙块无重力，NPC 不模拟完整日常作息。扩充并未将这些差异标记为已完成。

本地运行 `python tools/build_windows.py` 生成 `build/windows-v0.6.1/毅川救我.exe` 与便携 ZIP。未自动发布远程 Release。
